使用方法：①确保你解包得到的曲绘是“Illustration #...”的格式，并放在一个叫“Texture2D”的文件夹里；②下载仓库里的py和csv文件，并把它们和Texture2D放在同一文件夹下（不要把它们放进Texture里去！）；③运行py文件

由于不可抗力因素，部分曲名中的特殊符号会被替换为下横线

我没看到infinity heaven的曲绘的编号，你可能得自己重命名

编号对应曲绘的表即为“illustrations_chart.csv”

若不小心打开了csv文件或者你想加新的编号，请以CSV UTF-8的格式保存（不能直接保存！要另存为，并在“文件类型”那里找到到CSV UTF-8格式，然后替换原文件）
